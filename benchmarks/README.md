# Benchmarks

Benchmark suite definitions, issue fixtures, and run artifacts will live here.

Suggested structure:

```text
benchmarks/
  suites/      Curated benchmark definitions
  fixtures/    Small local fixtures for tests and development
  results/     Local benchmark outputs excluded or pruned as needed
```

Historical GitHub issue data should include enough information to reproduce a run: repository URL, issue URL, base commit, setup steps, and test command.
